# How to read and research

The [chapter index](conversation/chapters.md) follows the argument in the order it happened. If you’re testing a particular case, start with the record below, find the relevant exchange, and follow the cited source to the passage that carries the inference. Use the original records to check any quoted wording, dates, and measurements. Where the notes mention local scans, start with the originating publication in the source library.

The [live tally](research/argument-thread-audit-20261028/live-debate-tally.txt) records explicit challenges, successful defenses, and open items. It can change when new evidence changes a particular result. The [Shroud register](research/shroud-challenge-register-20261104.json) tracks that debate separately. A Jenga block names a feature an explanation has to account for. A tally records what happened when a specific objection was tested. Correlated observations can belong to several blocks, so neither count translates directly into probability. Use the dated ledger for the current disposition and the transcript to see how the participants reached it.

For a new challenge, write down the claim, the source carrying it, the specific contradiction or alternative, and what evidence would distinguish the explanations. Then check the strongest existing response and revise the claim if the evidence calls for it. A complete entry records the outcome, its scope, and the next observation that could change it.
